SODY — мобильное PWA-приложение. Бета-версия.

УСТАНОВКА НА САЙТ
1. Скопируйте все файлы и папку icons на HTTPS-хостинг (например /ritm/).
2. Откройте https://ваш-домен/ritm/ в браузере.
3. На iPhone: Safari → Поделиться → На экран «Домой».
   На Android: Chrome → меню → Установить приложение.

ВОЗМОЖНОСТИ
- Главный экран с дозировками, расписанием и прогрессом.
- Неделя и месяц, отметки выполненных приёмов, карточки препаратов.
- Добавление/изменение/удаление, фотографии упаковок до 500 КБ.
- Импорт TXT, MD, CSV, JSON, PDF, DOCX (PDF/DOCX через внешние библиотеки при наличии интернета).
- Импорт двухэтапный: просмотр распознанных строк перед добавлением.
- Экспорт и восстановление резервной копии.

ОГРАНИЧЕНИЯ
- Это клиентская версия без аккаунтов, синхронизации и push-уведомлений.
- Хранение только в localStorage текущего браузера; возможна потеря при очистке данных.
- Распознавание простых строк, сложные документы могут требовать ручного исправления.
- Приложение не назначает дозировки, не проверяет взаимодействия и не заменяет врача.
- Демо-данные содержат пустые дозировки; удаляются/редактируются вручную.

ПЕРЕИМЕНОВАНИЕ
Локальное хранилище сохраняет старый ключ ritm-pwa-v1 для совместимости с существующими данными.
Переименование GitHub и папки /ritm/ выполняется отдельно; перемещение на другой адрес не переносит localStorage автоматически.
